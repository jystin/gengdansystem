# 兴祥机械跟单小程序

这是一个面向兴祥机械内部生产的微信小程序跟单系统 MVP，首期采用微信云开发思路，先把以下核心闭环跑通：

- 订单创建与流转单生成
- 二维码扫码进入工单
- 当前工序完成与自动流转
- 管理员兜底干预
- 仅管理员分享链接/二维码可申请入驻
- 申请后进入待审批，管理员审批通过后才可访问内部页面
- 历史记录与基础统计

## 目录结构

- `miniprogram/`：小程序端
- `cloudfunctions/`：云函数预留
- `admin/`：Web 管理后台预留
- `common/`：共享常量与数据结构预留

## 当前状态

当前版本提供可运行前端与本地 mock 数据，并已补齐入驻审批与内部访问拦截流程；后续会接入云数据库与正式账号体系。
